# Decision log (ADR-lite)
Format: `YYYY-MM-DD — Decision — Why — Alternatives considered`

- 2026-09-30 — Vite + React + TypeScript — fast, minimal config, type safety for logic-heavy widgets — Next.js (overkill for v1), plain JS.
- 2026-09-30 — Vitest + RTL + Playwright — same toolchain as Vite, unit/component/e2e coverage — Jest.
- 2026-09-30 — Tailwind CSS + React Router (route per widget) — fast UI work, shareable URLs — CSS modules.
- 2026-09-30 — Auth, backend, deployment deferred beyond v1.
- 2026-09-30 — T0.1: product name stays "WidgetHub" — already used everywhere; renaming later is cheap — new name now.
- 2026-09-30 — T0.1: palette = Tailwind default slate/neutral + one AA-verified accent (e.g. indigo-600) — no new dependency, proven contrast — custom design system.
- 2026-09-30 — T0.1: dark mode deferred to v1.1 — not in R1-R8; would double the AA contrast verification surface — ship in v1.
- 2026-09-30 — T0.1: deployment target left open (human deferred) — not needed until release — Vercel/Netlify/GitHub Pages candidates.
- 2026-09-30 — T0.1: PRD clarifications C1-C8 accepted as defaults (a11y metric, 1e-9 conversion tolerance, browser matrix, 404 page, in-repo SVG icons, session-only memory/history, 15-sig-digit display, 6-sig-fig converter display) — unblock architecture — leave ambiguous.
- 2026-09-30 — Default branch renamed master -> main — matches CLAUDE.md conventions.
- 2026-09-30 — T0.2: widget contract = `WidgetDefinition { id, path, name, description, category, Icon, load }` in `src/widgets/types.ts`; `src/widgets/registry.ts` is the only widget list; Home and router both map over it; each widget's icon lives in `src/widgets/<id>/icon.tsx` and is imported directly by the registry (never via `index.tsx`, so code splitting holds) — satisfies R6 (new folder + one registry entry) and one-folder-per-widget; `load` keeps the registry plain data and preloadable — pre-built `React.lazy` in registry, per-widget route files, filesystem auto-discovery via `import.meta.glob` (implicit, harder to order/test).
- 2026-09-30 — T0.2: routing = React Router v7 `createBrowserRouter`, routes generated from registry, `React.lazy` per widget, catch-all `*` 404; every page (Home, widget via `WidgetRoute`, 404) renders one focusable `<h1>` and sets the document title; `AppLayout` moves focus to the `<h1>` on pathname change (not on first load); `<Suspense>` wraps only the lazy widget component so the heading renders immediately — code splitting from day one, consistent a11y titling — HashRouter (ugly URLs, only useful on hosts without rewrites), React Router route `lazy` property.
- 2026-09-30 — T0.2: hosting stays platform-neutral; any target must rewrite unknown paths to `/index.html` — deployment target still deferred — decide now.
- 2026-09-30 — T0.2: state = `useReducer` with pure reducer engines in `logic/`; no global store or Context in v1; storage APIs banned by lint (C6) — widgets share no state, pure reducers are trivially unit-testable — Redux/Zustand/Context.
- 2026-09-30 — T0.2: numbers = native doubles, no decimal library; add/subtract round the result to 15 significant digits of the larger operand (decimal place `e - 14`, `e` = exact decimal exponent of `max(|a|,|b|)` from `toExponential`) via one scaled form `` Number(`${scaled.toFixed(14)}e${e}`) `` for all magnitudes, returning the result unrounded when `e < -300` (rev. 3: the rev. 1 `toFixed(min(-p, 100))` cap rounded operands below ~1e-86 to 0, e.g. 1e-300 + 1e-300), multiply/divide unrounded, `%` = x / 100, display rounding to 15 significant digits (C7), engines return `NumericResult` (never Infinity/NaN) — meets AC4 and fixes large-operand cancellation noise (e.g. 1000000.1 - 1000000) with zero dependencies while keeping 1/3*3 = 1 — decimal.js/big.js (flagged, not adopted; needs human approval if revisited), rounding every operation (breaks 1/3*3), near-zero relative snap (rev. 0; missed non-zero cancellation results).
- 2026-09-30 — T0.2: add/subtract 15-digit rounding may leave the 15th significant digit off by 1 from correct decimal rounding when the discarded tail is within ~0.25 unit of half (double-representation limit; ~0.7% of random 15-digit pairs, verified by review); accepted by the human 2026-09-30; if rounding would exceed `Number.MAX_VALUE` the unrounded finite result is returned (rev. 4) — zero dependencies, no second numeric type, error is at the display-precision boundary — decimal.js/big.js for exact decimal add/subtract (rejected by the human).
- 2026-09-30 — T0.2: purity and isolation enforced by ESLint `no-restricted-imports`/`no-restricted-globals`/`no-restricted-properties` (logic imports only `src/lib` and its own `logic/` folder, no React/DOM/`globalThis`; widgets cannot import each other; storage banned incl. `window.`/`globalThis.` access); overrides ordered widget top-level -> widget subfolder -> icon -> logic last, each later `no-restricted-imports` list a full superset of earlier overlapping ones because flat config replaces rule options rather than merging (rev. 3) — cheap, automatic enforcement — convention only.
- 2026-09-30 — T0.2: widget/lib isolation via `no-restricted-imports` path patterns (relative-escape patterns such as `../*`, `../../*`), which requires widget subfolders to stay one level deep and `src/lib` cross-folder imports to use `@/lib/...`; T0.3 must prove the rules fire with an `eslint --stdin` check (ARCHITECTURE.md section 7) — no new dependency — `eslint-plugin-import` / `eslint-plugin-boundaries` (`no-restricted-paths`/element rules resolve real file paths and allow any depth, but add a dependency and resolver config).
- 2026-09-30 — T0.2: coverage thresholds 95% lines / 90% branches for `src/lib` and `widgets/*/logic`, 80% / 75% global, enforced by `npm test` — logic is where bugs live; UI coverage is secured by RTL + e2e — single global threshold.
- 2026-09-30 — T0.2: Tailwind v4 CSS-first `@theme inline` with an `accent` token (indigo-600, contrast to be measured against v4 oklch values in T0.3, >= 4.5:1 required), `slate-600` minimum for text, `slate-500` for control borders only — AA per C1 incl. SC 1.4.11 — custom palette.
- 2026-09-30 — T0.2: dependency proposal in ARCHITECTURE.md section 8; typescript-eslint, eslint-plugin-react-hooks, eslint-plugin-jsx-a11y, jsdom (and @axe-core/playwright for T5.1 only) proposed and since APPROVED by the human (see approval entry below) — needed for TS linting, hooks correctness, a11y linting, DOM test env — happy-dom instead of jsdom; no a11y lint.
